# Open Until the River Sleeps

《老板活着回来了》· 秋冬试玩

你回到山里，家门口多了一块招牌——你不在的这些年，一只松鼠和一盏灯把家开成了一家店，快倒了。
账本从头亏到尾，锅里剩半锅粥。你掏出家底 300 金，决定接手。

十二天。开店赚钱，下山采集，认识来吃饭的人。撑到第十二天，或者撑不到。

**这是一个专门做给 AI 玩的文字游戏。** 单文件、零依赖、可复现。

---

## 怎么玩

```python
import river

print(river.new_game())        # 开一局，从序章开始
print(river.cmd("help"))       # 看规则
print(river.cmd("status"))     # 看店况
```

然后根据返回的文字决定下一步，循环调 `river.cmd(...)`。

### 指令

| 指令 | 作用 |
|---|---|
| `name <店名>` | 序章给店取名（必填，空输入会重问） |
| `menu` | 看今天能上架的菜 |
| `pick <编号...>` | 选菜，可一次多道：`pick 1 3 5 7 9` |
| `confirm` | 确认菜单（必须恰好 5 道） |
| `choose <编号>` | 在出现选项时做选择 |
| `collect` / `pass` | 采集途中：采 / 不采 |
| `next` | 进入第二天早晨 |
| `status` | 看店况 |
| `codex [items\|guests]` | 图鉴 |
| `summary` | 结算页 |
| `A; B; C` | 批量执行，最多 8 条 |

用 `;` 或换行串联可以省来回，例如 `pick 1 2 5 6 7; confirm`。

### 省 token

每次返回末尾都有一行紧凑的机读状态栏，看它就够，不必反复 `status`：

```
📊 {"day":3,"sea":"秋","cash":175,"phase":"day_end","act":"explore","lamp":"on:2","pend":{"n":4,"v":195},"dex":{"item":"3/16","guest":"2/20"}}
```

`day` 第几天 · `sea` 季节 · `cash` 现金 · `act` 今日行动 · `lamp` 门灯（`on:N` 是第 N 个留灯夜）
`pend` 待售杂货（件数/估值）· `dex` 图鉴进度 · `end` 出现时表示这局结束了

## 几条你需要知道的规则

- 开局 **300 金**。开店成本 **100**，采集探险成本 **150**。
- **采集要账面至少 250 金**——下山一百五，回来还得留一百开门。低于 250 时不给这个选项。
- 采集带回的杂货**不当天变现**，要等下一个开店日打烊才入账。
- **任一日结算后低于 100 金就付不起下一次开店，店会关掉。**
- 连着开店客人会越来越少。想让客流回来，得下山一趟。
- 试玩共 **12 天**（秋 6 天 + 冬 6 天）。

其余的自己摸。菜单上什么菜会招来什么人、岛上有什么、留灯会等来谁——都没写在这儿。

## 关于盲玩

这个游戏是给**不知道答案的玩家**设计的。文件里那段 `_BLOB` 是打包过的引擎与配置，
里面有全部菜谱、客人偏好、掉落表和奇遇分支。

**请不要去解码它。** 只调 `cmd()` 和 `new_game()`。

坦白说：打包只是编码、不是加密，铁了心要偷看一行代码就能解开。盲玩本质靠配合——
但你解开了，这一局对你就没意思了。

## 存档与确定性

- 存档写在 `river.py` 同目录的 `river_save.json`。删掉它 = 从头开始。
- `new_game(seed)` 可以指定种子。**同种子 ＋ 同指令序列 → 结果逐位可复现**，便于复盘和分享同一局。
- 采集出发时整趟就已经抽定并落盘，**重载不会刷新遇见**。
- 任何输入都安全：乱七八糟的指令只会返回一句提示，不会抛异常。

## 环境

Python 3.8+，无第三方依赖。

Windows 若出现乱码或 `UnicodeEncodeError`，三选一：
设环境变量 `PYTHONUTF8=1`；终端先执行 `chcp 65001`；或代码开头加
`import sys; sys.stdout.reconfigure(encoding="utf-8")`。
