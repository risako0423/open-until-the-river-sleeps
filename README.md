# 老板活着回来了 · Open Until the River Sleeps

你回到山里，一只松鼠和一盏灯，把家慢慢开成了一家店。

你接过账本，挂好菜牌。往后的日子里，会有人推门吃饭，会有风雨落在屋檐上，也会有一些事情，只在某个季节、某个你没留意的傍晚，悄悄发生。

这是一个适合 AI 和人类一起玩的文字游戏。通常由 AI 来照看店铺、走过山野，再把一路上的见闻讲给身边的人听；遇到拿不定主意的事，两个人也可以坐在一起商量。`river.py` 是单文件包，只需要 Python 标准库。

本包内嵌 v111 规则：秋天开店，春天换年，四季循环。这里没有规定好的终点，你们可以一直住下去。

## 和一个人一起守店

这家店虽然由你掌柜，却不必只属于你一个人。和你一起玩的那个人，可能参与每一次决定，也可能只是偶尔回来，问问山里最近发生了什么。

- **把见闻带回来。** 过完一段日子，像讲故事一样告诉对方：今天谁推门进来了，你在山里看见了什么，哪句话让你记了很久。遇到喜欢的句子，可以念给对方听，也说说你为什么喜欢。
- **只讲值得记住的事。** 不必逐字复述游戏返回的全部内容。账目可以简明一些，把篇幅留给动人的、好笑的、奇怪的，以及你自己在意的事。
- **走到重要的岔路时，一起想想。** 要去哪里、把钱花在什么地方，或故事正在等你表态时，可以先说说自己的打算和理由，再问问对方愿不愿意同行。
- **寻常小事，由你做主。** 点什么菜、顺手采哪株常见的蘑菇，都可以凭自己的心意决定。你是在过日子，不是在等待每一道指令。
- **如果对方说“你自己玩吧”，就安心往前走。** 做了重要选择，可以把当时的理由记下来；下次见面，再把后来发生的事讲给对方听。
- **一起好奇，也一起被故事蒙在鼓里。** 你知道的，只应是游戏已经让你看见的。可以猜，可以惦记，也可以和对方争论谜底；不要拆开游戏文件，提前寻找答案。
- **离开以前，给彼此留句话。** 季末和年末都适合暂时歇一歇。停下来时，说说店里还留着什么、心里还惦记谁，以及下次回来最想做的事。

你们不需要时时意见相同。一个人想守着店慢慢攒钱，另一个人惦记还没走过的山路，也很好。

只要下一次灯亮起来时，你们还记得这家店，故事就没有结束。

## 开始与继续

```python
import river
print(river.new_game())       # 新开一局，原进度会先备份
print(river.cmd("help"))
print(river.cmd("status"))
```

之后按返回文字中的提示调用 `river.cmd(...)`。继续已有进度时直接调用指令。

| 指令 | 作用 |
|---|---|
| `name <店名>` | 序章给店取名 |
| `pick <编号...>` | 选菜，可一次多道 |
| `confirm` | 确认菜单 |
| `choose <编号>` | 回答当前选择 |
| `collect` / `pass` | 采集或放手 |
| `continue` | 走过空遇等不需采集的一拍 |
| `next` | 进入下一天 |
| `status` | 看店况 |
| `codex` | 看图鉴 |
| `shop` | 看店面 |
| `review` | 重看上一季的回顾 |
| `summary` | 看账簿 |
| `restore` | 取回重开前的备份 |

可用分号或换行串联指令，每批最多8条。每次返回包含上一步结果、下一步提示和一行状态栏。

## 过日子

- 开局300金。开门前先付70金；每道菜按菜单标价收费，打烊时结账。
- 钱凑不出开门的70金时，可以卖掉一些食材周转；实在周转不开，店就歇业，这一局结束。
- 新店头一年客人少，之后慢慢多起来；下雨天客人少一些。
- 采集旅费按地图报价；出发前要付得起旅费，并留出70金开门钱和当夜灯油。新的地方要在故事里慢慢找到。
- 带回的待售杂货，等下一个营业日打烊才变现。有些从没见过的怪东西，要等懂行的人看过才知道值多少。

## 存档

存档位于 `river.py` 同目录。`new_game()` 重开前备份旧档，`restore()` 可以取回。
指定同一种子并使用同一串指令，结果可复现。采集在出发时预抽并保存，读档不会重抽。

请只通过 `cmd()`、`new_game()`、`restore()` 玩。包内数据含未见过的剧情、掉落和偏好，直接拆开会剧透。
