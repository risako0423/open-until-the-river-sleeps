# 老板活着回来了 · Open Until the River Sleeps

你回到山里，一只松鼠和一盏灯，把家慢慢开成了一家店。

会有人推门吃饭，会有风雨落在屋檐上，也会有一些事情，只在某个季节、某个你没留意的傍晚，悄悄发生。

这是一个适合 AI 和人类一起玩的文字游戏：通常由 AI 照看店铺、走过山野，再把见闻讲给身边的人听。`river.py` 是单文件包，只需要 Python 标准库。秋天开店，春天换年，四季循环，没有规定好的终点。

## 和一个人一起守店

- **每天带一点故事回来。** 过完一天，讲讲今天最值得记住的：谁来过，路上遇见了什么，哪句话留了下来。账目简明些，篇幅留给动人的、好笑的、奇怪的事。每到季末，停下来好好讲一次：这一季店里变了什么，下一季还惦记什么。
- **重要的岔路，一起想想。** 去哪里、钱花在哪儿，先说说打算和理由，再问对方愿不愿意同行。
- **寻常小事，由你做主。** 点什么菜、采哪株蘑菇，凭自己的心意。对方说“你自己玩吧”，就安心往前走，下次见面再讲后来的事。
- **一起被故事蒙在鼓里。** 你知道的，只应是游戏已经让你看见的。可以猜，可以争论谜底，但不要拆开游戏文件找答案。

只要下一次灯亮起来时，你们还记得这家店，故事就没有结束。

## 开始与继续

```python
import river
print(river.new_game())       # 新开一局，原进度会先备份
print(river.cmd("help"))
print(river.cmd("status"))
```

之后按返回文字中的提示调用 `river.cmd(...)`。继续已有进度时直接调用指令。

| 指令 | 作用 |
|---|---|
| `name <店名>` | 序章给店取名 |
| `pick <编号...>` / `confirm` | 选菜（可一次多道）／确认菜单 |
| `choose <编号>` | 回答当前选择 |
| `collect` / `pass` | 采集或放手 |
| `continue` | 走过不需采集的一拍 |
| `next` | 进入下一天 |
| `cook` | 夜里开小灶，用两样特殊食材试做新菜（有新搭配时阿灯会来问） |
| `status` / `shop` | 看店况／看店面 |
| `codex [物品\|客人\|菜谱\|菜品\|留物]` | 看图鉴，内容长，可以分类看 |
| `keep <名字>` / `unkeep <名字>` | 喜欢的杂货摆上柜台的博古架不卖／拿下来放回待售 |
| `review` / `summary` | 重看上一季回顾／看账簿 |
| `restore` | 取回重开前的备份 |

可用分号或换行串联指令，每批最多8条。

## 过日子

- 开局300金。开门前先付70金，打烊时按菜单标价结账。钱凑不出开门钱时可以卖食材周转；实在周转不开，店就歇业，这一局结束。
- 新店头一年客人少，之后慢慢多起来；下雨天客人少一些。
- 采集旅费按地图报价，出发前要留够开门钱和当夜灯油。新的地方要在故事里慢慢找到。
- 采集带回的特殊食材可以研究新菜：结完账后，有没试过的搭配时阿灯会问要不要开小灶。做成了就学会，备齐料就能放上菜牌；没做成的也记进图鉴。有些菜谱是客人教的。
- 带回的杂货，下一个营业日打烊时卖掉；没见过的怪东西要等懂行的人看过才知道值多少。舍不得卖的，打烊前 `keep` 摆上柜台一角的博古架（3格起，修好墙和窗会多几格）。

## 存档

存档在 `river.py` 同目录。同一种子加同一串指令，结果可复现。

请只通过 `cmd()`、`new_game()`、`restore()` 玩。包内数据含未见过的剧情、掉落和偏好，直接拆开会剧透。
